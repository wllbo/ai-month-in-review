# AI Month in Review

Keeping up with AI is a part time job nobody assigned you. New model Monday, new agent framework Tuesday, and by Friday the thing you learned Monday is deprecated. (It also, finally, makes me read the 50 tabs I keep promising to get to.)

So once a month I go through everything that actually shipped, cut the hype, and turn the rest into a talk for working software engineers: which models are worth switching to, what changed in the coding agents you already use, the prompting tricks worth copying, and the security holes everyone ignores until the postmortem. Everything links back to its source.

Each edition is called **Knowledge Cutoff: \<Month\> \<Year\>**, borrowing the LLM term (here the model that needs updating is you).
